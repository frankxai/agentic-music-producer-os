# Workflow worksheets

Copy the relevant worksheet into a working record. Replace placeholders with your own decisions and retain unknowns; this guide is not a release approval.

## Artist profile
Public spelling / legal contracting party / identity type / one listener promise / sonic boundaries / human and generated contributions / name evidence / actual platform IDs / owner / next gate.

## Album bible
Thesis in one sentence / narrator and addressee / emotional beginning and turn / recurring motif / vocal contract / fixed palette / rotating grooves/instruments / unique signatures / track roles / sequencing arc / explicit exclusions / accepted evidence pointers / primary campaign and fallback.
Use70%fixed,20%rotated,10%signature as a design heuristic, not an audible-quality guarantee. Keep exact winners outside editable summaries.

## Recording selection
Work/revision and asset hash / lawful playback pointer / review context / matched-loudness method if actually used / timestamped hook/voice/groove/contrast notes / keep-revise-archive / fatal blocker / one smallest next intervention / exact reviewer verdict.
Hide provider, prompt, cost and prior verdict from the fresh-ears critic. A reviewer needs actual audio; record any unavailable playback explicitly.

## Cover brief
Selected recording/version / listener promise / one image motif / palette and recurring artist identity / focal subject / lighting/composition / typography handled separately if needed / exclusions / owned or licensed references / native Suno or image-tool path / paid allowance / destination specs checked at execution / actual output hash / visual approval.
Keep editable originals and inspect small-thumbnail legibility. A beautiful image still needs correct dimensions, metadata and rights for the destination.

## Music video brief
Selected master hash / full duration and chosen excerpt / narrative versus performance choice / recurring visual identity / approved character/likeness references / section-to-scene map / two-three anchor frames / beat and emotional cut targets / lip-sync need / original master as soundtrack / provider job quote / attempts and cap / export aspect ratios / final audio and continuity QA.
Test one15–30secondexcerpt before a full film. Keep generated scene audio from accidentally replacing the approved track. A video export is not a platform delivery.

## Frozen release packet
Release/work/recording/version IDs / primary artist and actual profile identifiers / title/version/language/explicit flags / contributors and accurate roles / composition and master owners / lyrics and human authorship / AI model/source contribution / samples/voice/likeness permission / dated provider creation/download entitlement / agreed splits / master/artwork hash and evidence pointers / actual technical QA / release date/territory / accountable approval bound to exact revision.
After authorized submission: actual distributor submission ID/time/payload and platform exceptions. After live verification: correct artist URLs and metadata. No fake ISRC, UPC or receipt.

## Campaign and amplification brief
Listener moment / primary strategy and fallback / why now / durable channel and discovery channel / asset family / approved public claims / placements/community fit / permission and sender account / tracking plan / one test variable / observation window and denominator / cash and per-job caps / stop/change rule / actual receipts and outcomes.
Consumer assets lead with the song. Creator assets teach one production decision and may link to the OS without making listening contingent on buying it.

## Postmortem
Hypothesis as originally written / actual artifacts and external receipts / cohort/window/source / metrics and denominators / planned versus reconciled costs / founder minutes / surprises and confounders / what worked or failed / conclusion scope / next experiment / private artist preference / reusable process improvement.

## Public process case study
Starting problem / dated work / creative choice / actual artifact stage / measurable result with denominator/window / total known costs and unresolved actuals / what changed / limits / customer-reusable lesson / approved public evidence.
A useful honest case study can demonstrate a better process before it demonstrates commercial music success. No invented fan reaction, testimonials, revenue or platform receipt.

## Template change proposal
Source friction and evidence / affected buyer job/module / original versus proposed behavior / generic example / compatibility class / privacy/rights check / acceptance test / migration with backup/rollback / version/changelog / adoption observation.
Artist-specific taste stays private. Update the method when it reduces repeated work for buyers.
