# Music Media Policy

Private lossless masters, stems and sensitive session evidence remain in approved private storage. Public listening and web use receive versioned compressed renditions with stable asset IDs, checksums, credits, rights status, captions/transcripts where applicable and exact placements. Drive may hold review/handoff packages; it is not a production streaming origin.

Only approved immutable renditions publish. Replacing audio creates a new version. Cover art, visualizers and video follow the same asset contract and must not fabricate plays, platform status, partnerships or release evidence. A user must control playback; cinematic web audio never autoplays without consent.
